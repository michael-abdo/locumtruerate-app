Test Instructions

This page tests the modal dialog implementation in test-paycheck-validation.html

Test 1: Modal Appearance
  1. Click "Open Test Page" below
  2. In the iframe, click "Run All Tests" WITHOUT loading the calculator first
  3. Verify: A modal dialog should appear with an error icon and message
Test 2: Modal Action Button
  1. When modal appears, click "Load Calculator First" button
  2. Verify: Modal closes and calculator loads
  3. Verify: Calculator iframe becomes visible
Test 3: Keyboard Navigation
  1. Trigger modal again (reload page and click "Run All Tests")
  2. Press ESC key
  3. Verify: Modal closes
  4. Trigger modal again and press Tab
  5. Verify: Focus stays on the action button (focus trap works)
Test 4: Overlay Click
  1. Trigger modal
  2. Click on the dark overlay (outside modal content)
  3. Verify: Modal closes
Test 5: Mobile Responsiveness
  1. Resize browser window to mobile width (< 640px)
  2. Trigger modal
  3. Verify: Modal adapts to mobile layout
  4. Verify: Button spans full width on mobile
